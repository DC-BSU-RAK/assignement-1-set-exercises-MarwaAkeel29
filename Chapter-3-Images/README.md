# Chapter 3 – Three Images ☑️ (+ Styling Those Divs 💡 Bonus)

This project includes both the **mandatory** and **bonus** tasks from Chapter 3 of the HTML & CSS module.

---

## ✅ Mandatory: Three Images

**Title:** *Timeless Treasures: Relics of the Past*

A nostalgic gallery showcasing three themed vintage images:  
- 📚 Old books on a wooden table  
- ⌨️ A classic Smith-Corona typewriter  
- 🚗 Retro cars on a historic European street  

Each image includes:
- `alt` text describing the image
- `title` attribute for tooltips
- Correct width and height attributes (while preserving aspect ratio)
- CSS filter effects (sepia, contrast, brightness)
- Attribution under each image with:
  - Photographer credit
  - License type (all Pexels - free for commercial use)
- File sizes optimized to be under 300KB

**Styling highlights:**
- Warm vintage color palette
- Elegant serif typography (Merriweather)
- Sepia image filters with subtle hover effects
- Responsive layout with consistent image containers
- Semantic HTML5 structure (header, main, section, footer)

---

## 💡 Bonus: Styling Those Divs

This optional task demonstrates advanced CSS skills by recreating a styled layout with four uniquely decorated `<div>` elements.

Each box (A–D) is customized using:
- `box-shadow` (outer and inset)
- `outline` with multiple layered shadows
- `border-radius`
- `text-shadow`
- Custom colors and spacing

Includes:
- `style.css` for base layout
- `additionalStyle.css` for bonus styling enhancements
